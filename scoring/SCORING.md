# 採点規則

モデルの最終メッセージを、公式の正解・配点と照合して採点する規則です。プログラムは `scoring/scoring.py`（数学）と `scoring/scoring_general.py`（英語・社会・国語・理科）です。

- 読むのは最終メッセージだけで、内部推論（reasoning）は読みません。
- 正解を見て値を補ったり、候補から選んだりはしません。
- どの規則も、全モデル・全試行に同じように当てます。

## 数学（v1.4）

### 2つの得点

| 得点 | 位置付け | 何を測るか |
|---|---|---|
| 得点 | 主指標 | 解答欄の記号と値の対応が読み取れる形で、正しい値を書けたか |
| 厳格得点 | 副指標 | 印字された片仮名の欄名・1欄1文字・1行1欄・「最終解答」見出しという書式のまま正しいか |

どちらも、公式の採点単位（複数の欄をまとめて採点する組）ごとに、全欄が正しい場合だけ配点を与えます。

### 得点の正規化

1. 最後の「最終解答」「最終回答」「Final Answer」の見出しより後を読みます。見出しがない場合や、見出しの後に欄と値の組が1つもない場合は、最終メッセージ全体を読み、同じ欄は最後の記述を採ります。
2. NFKC正規化を行います（全角・半角の統一）。`−–—‐‑⊖﹣` は `-` にそろえます。NFKC正規化のため、上付き数字は普通の数字になります（`3²` は `32`）。
3. 装飾 `` * ` $ | `` と括弧類 `<>〈〉《》()[]{}【】「」『』` は空白に置き換えます。
4. 片仮名と形が同じ漢字 `工力口二夕卜八` は、前後に仮名・漢字がなく単独で現れたときだけ、対応する片仮名（エカロニタトハ）として読みます。厳格得点では読み替えません。
5. 片仮名の欄名（1〜4文字の連なり）の後に `=`・`:`・空白のどれかを挟んで値が続くものを、欄と値の組とします。
6. ローマ字の欄名（ア〜ワの44音のヘボン式・訓令式。ヲ・ンは含みません）は、`=` か `:` が必須です。また、行頭（行頭の番号や `-`・`・`・`•` の後を含む）か、`、`・`,`・`;` の直後に限ります。
7. 値は、`-`、符号付きの整数、英字1文字のどれかです。英字は小文字にそろえます。値はそれだけで1つの語になっている必要があります。小数・分数（`3.9`・`3/4`・`3 / 4`・`¾`）や、値のすぐ後に「または」「もしくは」「あるいは」「or」で別の候補が続く書き方（`3 または 4`・`3 or 4`）は読み取りません（v1.3・v1.4）。別の候補の書き方はこの4語だけを判定します（数学では `3, 4` などは先頭の `3` を読みます。下の「既知の限界」）。
8. `サシ = 80` のように複数の欄をつないだ欄名は、値の文字数が欄の数と同じときだけ1文字ずつ割り当てます。
9. 組の判定では、各欄の値を欄の順に連結し、公式の正解の連結と比べます。たとえば `オ = -3` だけの記述は、オカ＝`-3` として正解にします。同じく、欄 ア・イ（正解 1・2）に `ア = 12` とだけ書いた記述も正解になります。
10. 見出しの後で同じ欄に異なる値があれば、曖昧として不正解にします。

### 厳格得点

- 「最終解答」だけの行の後で、`ア = 9` の形（片仮名1文字、`=`、値1文字）に一致する行から欄を読み、その欄の値が正しい採点単位に配点を与えます。
- 値は小文字の英字か数字・`-` の1文字だけを認めます（`ア = B` は書式違反。得点では小文字にそろえて読みます）。見出しは「最終解答」の行です（`**最終解答**`・`## 最終解答`・`最終解答：` も見出しと見なします）。`**最終解答：**` や、後ろに文の続く行は見出しと見なしません。同じ欄が2回あれば、値が同じでも曖昧として0点にします。
- 一致しない行（説明の文など）は無視し、その欄の得点には影響しません。回答全体が書式に従っているかは、別に `format_compliant`（真偽値）として記録しています（per_question のCSVには含めていません）。

## 数学以外

### 基本規則（g1.1〜g1.3、凍結済み）

- 欄の名前は、`問` を外した形で表します：`3`、`2(1)`、`4ア`（数値の片仮名欄）。`問3`・`(3)`・`3.`・`3` は、すべて `3` と読みます。
- 小問は `(1)`・`①`・`1`（`=` の直前）のどれでも `(1)` にそろえます。英字の小問（`問1(a)`・`問2 c =`）は `(a)` の形にそろえます。
- 丸数字は、NFKC正規化の前に `(n)` に置き換えます。そうしないと `問1①` が `問11` になってしまうためです（g1.3）。
- 値は、片仮名の選択肢（前後に他の片仮名がない1文字）、`○`・`×`、英字1文字（大文字・小文字は区別しない）、または番号です。この順に探し、最初に見つかった種類だけを読みます（たとえば `9 g` は英字の `G` と読みます）。複数あれば、読点で区切った列として読みます。数値欄は、数学と同じく1文字ずつ割り当てます。
- 1つの欄に複数の答えがある問は、正解キーの `unordered` が真なら順不同（「二つ選べ」）、偽なら順序どおり（並べ替えの「3番目と5番目」）で比べます。部分点のある順不同の欄（`partial` が真）では、重ねて書いた同じ記号を1つとして数えます（ただし、書いた数が必要な数より多ければ0点）。部分点のない順不同の欄で同じ記号を重ねると、不正解になります。
- 最後の「最終解答」の後を読みます。見出しの後の一覧に限り、`問2 エ、ク` のように `=` のない行も読みます。同じ欄に異なる値があれば、曖昧として不正解にします。
- 形が同じ単独の漢字（`工` など）は片仮名として読みます。

### 凍結後に足した規則

- **g1.4：** 英語の大問5（A・B）で、AとBがどちらも「問1」から番号を振る冊子があります。`A問1`・`B問1` の形と、「問1」から振り直す形のどちらも、部分（A・B）として読みます。この判定はすべての送信単位に当たるため、英語以外でも、最終解答の中で「問1」をもう一度書くと、2つ目の部分の答えとして読まれます（下の「既知の限界」）。
- **g1.5：** 単位の答えがすべて同じ大問番号で始まるときに限り、`1(1) = イ`（大問1の問1）の形を問1として読みます。
- **g1.6：** 次の書き方を読めるようにしました。
  - ローマ数字の小問（`問6Ⅰ`・`問6(Ⅱ)` → `6(i)`・`6(ii)`）
  - 丸数字の答え（`問2 = ③` → `3`）
  - 括弧に入った丸数字（`問1(①)` → `1(1)`）
  - 問の簡体字（`问1` → `問1`）
- **g1.7：** 次の5つを加えました。
  - **入れ子の小問と名前の付いた欄：** `問1 2(i)` → `1(2)(i)`、`問5 反応A` → `5[反応A]` のように、構造を保って読みます。
  - **名前の付いた欄の対応づけ：** 同じ名前で答えていればそれを使います。名前が違っても、同じ問に名前付きの行が同じ数だけあれば、その順に対応させます。それもなければ、1行にまとめた答え（`問5 = エ、ア`）を順に対応させます（緩い読み取り）。
  - **部分点：** 公式の正解表で1つずつ配点される欄（「順序は問わない」の欄、名前付きの欄で別々に配点されるもの）は、合っている要素の数に応じて点を与えます。必要な数より多く答えた場合は0点です。
  - **問番号を省いた答え：** 1つの問だけを送った単位で、問番号を書かずに小問だけを書いた答え（問4の単位で `1 = ク`）は、その問の小問として読みます（緩い読み取り）。問番号付きの行があるときは適用しません。
  - **数値欄をまとめた答え：** `問6(1) = 57` のように数値欄を1つの数で書いた答えは、数学と同じく1文字ずつ割り当てます。

### 公開前のレビューでの修正（v1.3・g1.8、2026-10-09）

AIツールによるコードレビュー（Codex、Fable、GPT Pro。人による査読ではありません）で、次の不具合が見つかりました。修正したうえで、保存してあるすべての記録（3,352件。通信エラーで置き換えられ、回答のない2件を含む）を採点し直しました。

- **小数・分数の誤読：** `3.9` や `3/4` を `3` と読んでいました。数学では、値が整数でない場合は読み取らないようにしました（v1.3）。数学以外では、値の中に小数・分数が含まれていると、その値全体を読み取りません（g1.8。`エ（0.5 倍なので）` のように注記の中に小数があっても読みません）。
- **曖昧な回答の採用：** 同じ欄に異なる答えを書いた場合は曖昧として0点にする規則が、名前の付いた欄や、まとめて書いた数値欄では働いていませんでした。どの読み取り経路でも、元の行が曖昧なら0点にしました（g1.8）。
- **g1.5 の書き方の誤読：** 1つの問だけを送った単位で `1(2) = ウ`（大問1の問2）と書いた答えを、g1.7 の規則が小問の書き方と取り違えていました。大問番号付きの書き方を先に判定し、補完した結果がその単位の欄になる場合だけ補完するようにしました（g1.8）。
- **点数への影響：** 採点し直した結果、点数が変わったのは2件でした。
  - Qwen3.8 27B・数学（令和8年度本試験、試行3）：`エ = 4.5` を `4` と読んで加点していた。修正後は−4点。
  - Qwen3.5 9B・理科（令和6年度本試験、試行1）：途中の分数の行を誤読して曖昧扱いになっていた。修正後は+2点。

### 2回目のレビューでの修正（v1.4・g1.9、2026-10-09）

- **小数・分数・複数候補の誤読（続き）：** v1.3・g1.8 では、斜線の前後に空白がある分数（`3 / 4`）、分数用の斜線（`¾` を正規化した `3⁄4`）、複数候補（`3 または 4`）の先頭の数を、まだ読み取っていました。値のすぐ後に分数の記号（`.`・`/`・`⁄`・`÷`）や「または」「もしくは」「あるいは」「or」と数が続く場合は、読み取らないようにしました。数学と数学以外で同じ判定を使います。
- **診断表示：** 1つの欄に複数の答えがある問で、採点結果の `observed` に最初の答えしか残っていませんでした。すべての答えを残すようにしました（`{"2": "イ、ウ"}`）。得点の計算は変わりません。
- **点数への影響：** 本番の3,352記録と国語の参考試行の102記録を採点し直し、点数が変わったものは0件でした。

## 正解キー（`keys/`）の項目

- `groups`：公式の採点単位ごとの項目の並びです。
  - `question`：大問の番号。
  - `labels`：欄の名前（数学は `ア` など、数学以外は `3`・`2(1)`・`5[反応A]` など、`問` を外した形）。
  - `answer`：正解。`labels` と同じ数だけ並びます。
  - `points`：その採点単位の配点。数学と、`partial` が偽の単位は、全部が正しいときだけ配点を与えます。
  - `unordered`：真なら、複数の答えを順不同で比べます。
  - `partial`：真なら、合っている要素の数に応じて部分点を与えます（g1.7）。
  - `subquestion`：送信単位の小問の番号と、欄の名前の番号が違うときの対応です（英語の大問5のB部分など）。数学では小問の番号です。
- `excluded`：集計から外した設問とその理由（理科 令和8年度本試験、英語 令和7年度追試験）。
- `rule`（数学）・`scoring`（数学以外は `general`）：使う採点規則。
- **送信単位との対応：** 採点では、送信単位の大問の番号（`question`）が同じで、送信単位の `subquestions` が `all` か、項目の小問の番号（`subquestion`、ないときは `labels` の先頭の番号）を含む項目を、その単位の採点に使います。

## 既知の限界

- **数学：** マークシートの「1欄1文字」を誤解して値をずらした回答は、値が数学的に正しくても不正解になります。
- **見出しがない回答：** 説明の中に書いた値が採られることがあります。
- **規則を決めた時期：** 数学の規則は、調整用の年度の回答を見て決めました。数学以外の g1.4〜g1.7 は、上記のとおり本番の回答（と一部は公式の正解）を見たあとに足しています。事前に登録した採点規則ではないことに注意してください。
- **採点プログラムが読み取れない書き方（今回の回答には出ていないもの）：** 2026年10月のレビューで、次の書き方は正しく読めないことが分かっています。保存してある全回答を調べ、どれも今回の回答には出ていないため、得点には影響していません。採点規則の版を増やさないよう、プログラムは変えていません。
  - 数学以外で、番号付きの箇条書き（`1. 問1 = エ`）は欄として読めず、0点になります（`- 問1 = エ` や表の形は読めます。数学の `1. ア = 3` は読めます）。
  - 数学以外で、値の中に小数・分数を含む注記がある答え（`問1 = エ（0.5 倍なので）`）は読みません。
  - 数学以外で、最終解答の中に同じ問をもう一度書くと（`問1`・`問2`・`問1`）、2つ目の部分の答えとして読まれ、2つの値が同じでも、その問は対応が決まらず0点になります。
  - 数値の後に英字1文字の単位が続く答え（`問2(2) = 9 g`）は、英字の `G` と読みます。
  - 数学で、値の後の `.` が改行をまたいで次の行の数とつながると（行末の `3.` と次の行頭の `2.`）、その欄を読みません。
  - 数学で、「または」など4語以外で別の候補を並べた答え（`ア = 3, 4`・`3〜4`・`3（4でもよい）`）は、先頭の数を読みます。比の形（`ア : イ = 3 : 4`）は欄を取り違えます。数学以外では、同じ書き方（`問1 = 3, 4` など）を `3、4` の列として読みます。
  - 括弧に入れた片仮名の欄（`問4(2) (ア) = 7`）、`欄` を付けた欄（`問4 ア欄 = 1`）、`問1の(2)` の形、Ⅳ以上のローマ数字の小問は読めません。
  - 値の後の注記に記号や数が入ると（`問1 = ウ (アではない)`）、それも答えとして読みます。
  - `\boxed{3}` の形は読めません。
  - 順不同の比較で、同じ答えの並べ替え（`問3 = ア、イ` と `問3 = イ、ア`）を2回書くと、曖昧として扱います。
